      5. Arquitectura Abierta (Apache 2.0)
      
Estructura MVC, endpoints REST y cómo desplegarlo

      

        El proyecto completo corre en Node.js + Express sin base de datos externa ni claves API obligatorias, y separa limpiamente conectores de datos, física de cultivos, análisis multicriterio y vistas.
      


      

        

          1. Router & Controller
          
Orquesta la carga inicial SSR (GET /), metadatos (GET /api/equations) y recálculos dinámicos (POST /api/analyze).

          routes/indexRoutes.js
          controllers/fieldShiftController.js
        

        

          2. Data Connectors
          
Consulta en paralelo NASA POWER (climatología + serie diaria), SoilGrids v2.0 y Georef AR con caché TTL y fallback JSON.

          models/agroModel.js
          data/zona_guamini_10ha.json
        

        

          3. Biophysical Engine
          
Penman-Monteith FAO-56, curvas de excedencia térmica, función de rinde FAO-33, calibración MAGyP y filtro Q0.05–Q0.95.

          models/extremesModel.js
          models/yieldModel.js
        

        

          4. MCDA & Views
          
Simula 12–72 meses en 3 sub-pasos, evalúa SAW-8/SAW-15/TOPSIS-15 y renderiza Leaflet, Turf.js, Chart.js y mini-tutoriales.

          models/mcdaModel.js
          views/index.ejs · public/js/client.js

cd field-shift-mvc-5
npm install
npm start
# Aplicación activa en http://localhost:3000

        

        

          
Despliegue de este Explorador en GitHub Pages

          

            1. Subir el repositorio a GitHub (rama main).

            2. Ir a Settings → Pages → Build and deployment.

            3. Elegir Deploy from a branch → Rama main → Carpeta /docs.

            4. Esta página estática funciona sin servidor gracias a que NASA POWER, SoilGrids y Georef AR habilitan CORS abierto.
          

          Aviso: toda decisión agronómica requiere validación de un ingeniero agrónomo local.
